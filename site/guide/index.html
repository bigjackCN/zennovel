快速上手

从第一句台词，到分支、变量、点画面选择和带倒计时的实时玩法，再到导出发布。入门五节十分钟就能走完，后面的按需要看。

最快的学法：新建故事时选一个模板——《樱花坡道》（分支和变量）、《一张照片》（点画面选择）、《夜班》（实时玩法）——打开看它是怎么搭的，再改成你自己的。

入门

1. 安装，新建故事

  1. 在首页下载 Windows、macOS 或 Linux 版。安装包暂未签名：Windows 上点「更多信息 → 仍要运行」，macOS 上右键选「打开」。
  2. 打开 ZenNovel，首先看到的是项目列表。
  3. 点 新建故事 下面的 空白项目，起个名字。也可以选一个模板，从现成的故事开始。

每个故事都是电脑上的一个文件夹，里面是 project.json 和它用到的图片、音乐。新故事存在哪里，写在项目列表上方，可以点 更改… 换位置。

2. 写台词

编辑器分三栏：左边是场景列表和项目内容（故事 流程图 角色 变量 素材），中间是当前场景的卡片，右边是预览。

  • 一句台词就是一张 台词 卡片。打完一句按 回车 会自动写下一句；Shift+回车 是换行。
  • 卡片左边选说话的人：旁白 或某个角色。
  • 场景最下面的 添加： 一排按钮，用来加入其他种类的卡片：背景、角色登场、选项、音乐……
  • 卡片右上角可以上移、下移、删除。Ctrl+Z 撤销，Ctrl+Y 重做（Mac 上是 ⌘+Z 和 ⌘+Shift+Z）。
  • 所有修改自动保存，标题栏会显示 已保存。

3. 背景、角色和声音

背景

加一张 背景 卡片，从下拉框里选图片（或 上传图片…），也可以用 纯色。勾上 淡入，换背景时会慢慢过渡。

角色和立绘

左边点 角色 → + 新角色：填名字、选名字颜色，然后 添加立绘。每张立绘有一个表情名，比如「开心」「难过」。

  • 角色登场：选角色、表情和位置（左边 / 中间 / 右边）。同一个角色再登场一次，就是换表情或换位置。
  • 角色退场：让他离开画面。

音乐和音效

  • 音乐：播放音乐（可以设循环和音量）或 停止音乐（当前音乐会淡出）。换一首音乐也是再放一张音乐卡。
  • 音效：播放一次，比如关门声、快门声。

图片和声音都在 素材 里。可以把文件直接拖进来，大小不限；每个素材旁边写着它用在几处，也可以一键替换。

4. 选项和多个场景

左边点 + 新场景 新建场景。场景之间用三种卡片连起来：

  • 选项：上面是提问文字（可以不写），下面每一行是一个选项和它的去向——某个场景，或 继续往下。
  • 跳转：不问玩家，直接去另一个场景。
  • 结束：故事在这里结束。

流程图 里能看到所有场景和它们通向哪里：实线是跳转，虚线是选项。拖动场景摆放位置，或点 自动排列；点一个场景就进去编辑。

故事从带 ★ 的场景开始。想换起点，选中场景后点 设为起点。

5. 试玩、外观和故事检查

  • 预览：点画面或按 空格 继续，按 ← 回退，用 ↑ ↓ 和 回车 选选项。预览下面三个按钮：▶ 从这一句（从正在编辑的卡片开始，上面的背景和角色会先摆好）、本场景、⟲ 从头播放。
  • 外观：预览旁边的 外观，调对话框的颜色、透明度、字号、圆角和高度，打字速度，选项按钮的颜色，以及播放器自带按钮的语言。
  • 完整试玩：右上角 ▶ 试玩，在新窗口里玩和玩家一模一样的游戏：标题画面、菜单（右键或 ☰）、存档读档、自动存档、历史记录。
  • 故事检查：左下角随时列出问题——跳转去了不存在的场景、图片丢失、场景结尾没有去向、有场景永远走不到……点 定位到这里 跳到出问题的卡片。

到这里，你已经能做一个完整的分支故事了。下面是让它更像“游戏”的部分。

进阶

6. 变量和条件

变量用来记住玩家这一路的经历：好感度、有没有拿到钥匙、走过哪些地方。

  1. 左边 变量 → + 新变量，选类型（数字 / 是 / 否 / 文字）和初始值。
  2. 改变它：在选项下面点 + 改变变量（选了以后：勇气 加上 1），或者在任何地方放一张 变量 卡片。可以加上、减去、设为、切换。
  3. 读取它：条件分支 卡片——如果……那么……否则……。点 + 且 / 或 可以组合多个条件（以下全部成立 / 以下任一成立）。
  4. 选项也可以 + 出现条件：只有条件成立时，这个选项才会出现。

7. 多结局和成就

  • 每个结局一个场景，最后放一张 结束；或者像上图那样，在同一个场景里用条件分支分出不同的结尾。
  • 成就 卡片：填玩家看到的名字（例如「真结局」）和 Steam API 名称（例如 ENDING_TRUE）。Steam 版会解锁对应的 Steam 成就，其他版本会在画面上弹出一个小提示。

8. 在画面上点选（《一张照片》的玩法）

不想用按钮？可以让玩家直接点画面里的东西。

  • 在选项下面点 + 在画面上点选，会打开一张大图：在画面上拖出一块区域，玩家点这里就选这一项。拖动方框移动，拖四个角改大小；之后点 调整 可以再改。
  • 角色登场 的位置选 自定义位置…，把图片拖到任意地方，拖右上角的圆点改大小，或者 铺满画面。把一个画面拆成几张同样大小的图层（照片里的每个人一层），就能按玩家的选择一层层替换。
  • 游戏菜单里的「保存画面」，可以让玩家把当前画面存成一张图片。

9. 实时玩法（《夜班》的玩法）

倒计时、手电筒、追着人跑的光……这些都只是普通卡片上的几个选项，不用写代码。

停顿

停顿 卡片：等几秒后故事自动继续，玩家不能跳过。用来留出时间，让画面里的事情发生。

限时选项

在选项卡片上点 + 限时，填秒数。会多出一行 ⏱ 时间到了，决定时间到了去哪里；不选去向，就继续往下。画面顶部有一条倒计时进度条。

移动

角色登场 卡片上点 + 移动：设移动用时和起点（当前位置 或 自定义起点）。人走过马路、车从远处开过来，都是这样做的。移动的时候故事照常往下走。

天黑和手电

背景 卡片勾上 天黑：只有鼠标附近被照亮，调 暗度 和 光圈，还可以 闪烁。鼠标（手机上是手指）就是手电。角色勾上 发光（不被黑暗遮住），就会在黑暗里亮着：路灯、车灯、亮着的窗户。

点角色、一直照着

选项上点 + 点某个角色：可点的区域会一直跟着这个角色的图片走，哪怕他在移动。再点 + 要一直照着：玩家要把光（鼠标）在他身上停够几秒才算选中，中途移开不清零。

画面上的数字：电量、倒计时

数字变量旁边点 画面显示与计时…：显示成进度条、数字或倒计时（分:秒），放在左上角或右上角；填 每秒减少，它就会随时间自己往下走（减到 0 为止，游戏暂停时不动）。进度条和倒计时为 0 时不显示，所以初始值设成 0，等到需要时再设值，它才会出现。

把它们串成一个游戏

《夜班》一分钟里的四件事，是靠一个叫「巡逻」的场景排出来的。它一直做三件事：

  1. 用 条件分支 看倒计时：时间到了就跳去「天亮」；到了某件事的时间、这件事还没发生过，就跳去那件事的场景。
  2. 停顿 0.5 秒。
  3. 跳转 回「巡逻」自己。

每件事的场景结束时跳回「巡逻」。新建一个《夜班》模板，打开 流程图 就能看到整个结构。

发布

10. 导出游戏

点右上角 导出游戏，选要哪些版本：

  • 网页：文件夹（index.html + assets） 适合体积较大的作品；单个 HTML 文件 方便直接发给别人。上传到 itch.io 时，把网页版打包成 .zip，作为 HTML 项目上传。
  • Windows 和 Linux：标准版（约 100 MB，每台电脑上显示都一样）。可以勾上同时打包成 .zip，方便上传 itch.io 或提供下载。
  • Steam：勾 为 Steam 准备，填 Steam App ID。会加上 Steam 成就和游戏内界面，存档可以用 Steam 云存档同步。详见 发布到 Steam。

如果故事检查里还有错误，导出前会提醒你。

11. 保存、备份和协作

  • 每个故事就是一个文件夹：可以复制、放进网盘，或者放进 git 仓库和别人一起改。项目列表里的 在文件夹中显示 能直接打开它。
  • 打开项目文件夹…：打开任意位置的项目，U 盘、共享盘、git 仓库都可以。
  • 导出项目文件：把整个项目存成一个 .json 文件，相当于一份备份；在项目列表点 导入项目 就能打开。导出的网页游戏（index.html）也可以导入回来。

Quick start

From your first line to branches, variables, picking things on the picture and real-time play with a countdown, then exporting. The basics take ten minutes; read the rest when you need it.

The fastest way to learn: when you create a story, pick a template — Cherry Blossom Hill (branches and variables), One Photograph (picking on the picture), Night Shift (real-time play) — see how it's built, then make it your own.

Basics

1. Install, start a story

  1. Download the Windows, macOS or Linux version from the home page. The installers aren't signed yet: on Windows click “More info → Run anyway”; on macOS right-click and choose “Open”.
  2. Open ZenNovel. You start on the list of projects.
  3. Under New story, click Blank project and give it a name. Or pick a template and start from a finished story.

Every story is a folder on your computer: project.json plus the pictures and music it uses. Where new stories go is shown above the list; click Change… to move it.

2. Write lines

The editor has three columns: on the left the scenes and the parts of the project (Story Story map Characters Variables Media), in the middle the cards of the current scene, on the right the preview.

  • Each line is a Line card. Press Enter at the end of a line to start the next one; Shift+Enter is a line break.
  • Pick who speaks on the left of the card: Narrator or one of your characters.
  • The Add: row at the bottom of the scene adds other kinds of card: background, show character, choice, music…
  • The top right of each card moves it up or down or deletes it. Ctrl+Z undoes, Ctrl+Y redoes (on a Mac, ⌘+Z and ⌘+Shift+Z).
  • Everything saves by itself; the title bar says Saved.

3. Backgrounds, characters, sound

Backgrounds

Add a Background card and pick a picture from the list (or Upload image…), or use a Solid color. Tick Fade in for a gentle change.

Characters and their pictures

Click Characters → + New character on the left: a name, a name colour, then Add picture. Each picture has an expression name, like “happy” or “sad”.

  • Show character: pick the character, the expression and where they stand (left / center / right). Showing the same character again changes their expression or spot.
  • Hide character: they leave the stage.

Music and sound

  • Music: Play music (with loop and volume) or Stop music (the current music fades out). To change the music, add another music card.
  • Sound: plays once — a door, a camera shutter.

All pictures and sounds live in Media. Drag files straight in, any size; each one shows where it's used and can be replaced in one go.

4. Choices and scenes

Click + New scene on the left to add a scene. Three kinds of card connect scenes:

  • Choice: an optional question on top, then one row per option with where it goes — a scene, or Continue below.
  • Jump: go straight to another scene without asking.
  • End: the story ends here.

The Story map shows every scene and where it leads: solid lines are jumps, dashed lines are choice options. Drag scenes around or click Arrange automatically; click a scene to edit it.

The story starts at the scene marked ★. To change it, select a scene and click Set as start.

5. Play, appearance, story check

  • Preview: click the picture or press Space to go on, ← to go back, ↑ ↓ and Enter to pick options. Under the preview: ▶ From this line (starts at the card you're editing, with the background and characters already in place), This scene, ⟲ From the start.
  • Appearance: next to the preview, set the dialogue box's colour, opacity, text size, corners and height, the typing speed, the choice buttons' colours, and the language of the player's own buttons.
  • The whole game: ▶ Play at the top right plays exactly what players get, in a new window: title screen, menu (right-click or ☰), saves, autosave, history.
  • Story check: the bottom left always lists problems — a jump to a scene that doesn't exist, a missing picture, a scene that ends without going anywhere, a scene nobody can reach… Click Show me to go to the card.

That's enough for a complete branching story. What follows makes it play more like a game.

Going further

6. Variables and conditions

Variables remember the player's journey: affection points, whether they found the key, where they've been.

  1. Variables → + New variable, then choose a kind (Number / Yes / no / Text) and a starting value.
  2. Change it: under an option, click + Change a variable (when picked: Courage add 1), or put a Variable card anywhere. You can add, subtract, set or toggle.
  3. Read it: an If / else card — if… then… otherwise…. + and / or combines conditions (all of these are true / any of these is true).
  4. Options can have a + Show condition too: the option only appears when it's true.

7. Endings and achievements

  • Give each ending its own scene, finishing with an End card — or, as above, split one scene into different endings with If / else.
  • Achievement card: the name players see (e.g. “True ending”) and the Steam API name (e.g. ENDING_TRUE). The Steam build unlocks that Steam achievement; other builds show a small notice on screen.

8. Picking on the picture (as in One Photograph)

Rather than buttons, players can click things in the picture.

  • Under an option, click + Pick on the picture. A large view of the stage opens: drag out an area, and clicking there picks the option. Drag the box to move it, drag its corners to resize; Adjust changes it later.
  • In Show character, choose a spot of my own… as the position, drag the picture anywhere, resize it with the dot at its top right, or Fill the stage. Split a picture into layers of the same size (one per person in the photograph) and you can swap them one by one as players choose.
  • “Save picture” in the game menu lets players keep what's on screen as an image.

9. Real-time play (as in Night Shift)

Countdowns, a torch, a light that follows people — each is just a setting on an ordinary card. No code.

Pauses

A Pause card waits a few seconds, then the story carries on by itself; players can't skip it. Use it to give things on screen time to happen.

Time limits

Click + Time limit on a choice card and set the seconds. A ⏱ Time runs out row appears: where to go when time is up (with no destination, the story continues below). A bar along the top of the screen counts down.

Movement

On a Show character card, click + Move: how long it takes and where it starts (where it stands or a spot of my own). That's how people cross the road and cars drive up the street. The story keeps going while things move.

Darkness and a torch

Tick Dark: lit only around the pointer on a Background card and set the Darkness and the Light size; it can Flicker too. The mouse (a finger on phones) is the torch. Characters with Glows (shows through the dark) stay lit in the dark: street lamps, headlights, windows.

Click a character, keep the light on it

On an option, + Click a character makes the clickable area follow that character's picture, even while it moves. Add + Keep the light on it and players must keep the light (the pointer) on it for a number of seconds to pick it; moving away pauses the count rather than resetting it.

Numbers on screen: batteries and countdowns

Next to a number variable, click On screen & countdown…: show it as a bar, a number or a countdown (min:sec), top left or top right. Set Goes down per second by and it runs down by itself (stopping at 0, and holding still while the game is paused). Bars and countdowns at 0 are hidden, so start at 0 and set a value when you want one to appear.

Putting it together

Night Shift's four events in one minute are scheduled by a scene called “On patrol” that keeps doing three things:

  1. An If / else checks the countdown: at zero, jump to “Dawn”; when it's time for an event that hasn't happened yet, jump to that event's scene.
  2. Pause for 0.5 seconds.
  3. Jump back to “On patrol”.

Each event's scene jumps back to “On patrol” when it's done. Create a story from the Night Shift template and open the Story map to see the whole shape.

Publishing

10. Export the game

Click Export game at the top right and choose the builds you want:

  • Web: a Folder (index.html + assets) for larger games, or One HTML file that's easy to send around. For itch.io, zip the web build and upload it as an HTML project.
  • Windows and Linux: the Standard build (about 100 MB; looks the same on every computer). You can also have each build packed as a .zip for itch.io and downloads.
  • Steam: tick Prepare for Steam and enter your Steam App ID. This adds Steam achievements and the Steam overlay; saves can sync with Steam Cloud. See Publishing on Steam.

If the story check still has errors, you'll be asked before exporting.

11. Saving, backups, teamwork

  • Every story is a folder: copy it, keep it in cloud storage, or put it in a git repository and work on it with others. Show in folder in the project list opens it.
  • Open project folder… opens a project from anywhere: a USB stick, a shared drive, a git repository.
  • Export project file saves the whole project as one .json file, a backup you can open again with Import project. An exported web game (index.html) can be imported back too.
