Windows macOS Linux 所有版本

能做什么

  • 像写小说一样写 一句台词一张卡片，回车写下一句。不用学脚本语言。
  • 分支和变量 选项跳转、好感度、条件分支，都从下拉框里选。
  • 边写边看 右边的预览就是玩家看到的游戏，改一句，马上看到效果。
  • 画面和声音 背景、立绘、配乐、音效，拖进来就能用，没有大小限制。
  • 导出到任何地方 网页、itch.io、Windows、Linux；Steam 版支持成就和云存档。
  • 作品是你的 每个故事就是电脑上的一个文件夹，可以备份、可以放进 git。
